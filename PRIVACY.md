# Privacy Policy

_Last updated: 8 November 2026_

Chat by Default is a free, open-source browser extension that switches chatgpt.com from the Work tab to Chat.

## Summary

Chat by Default does not collect, store, sell or share any data. It has no accounts, analytics, advertising, tracking or crash reporting, and it makes no network requests. The developer receives no data from it.

## What it does

It only runs on `https://chatgpt.com/*`. There, it finds the page's Chat/Work toggle and clicks Chat. It reads nothing else from the page and keeps nothing between visits.

## Permissions

It only asks to run on chatgpt.com, so it can click the toggle. It asks for no other permissions.

## The Safari app

On macOS, iOS and iPadOS, the app only shows how to turn the extension on in Safari. It collects no data either.

## Changes

Any changes to this policy will be made in this file. Its full history is in this repository's commit log.
